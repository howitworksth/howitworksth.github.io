แอป "howitworksth stats"

เป็นสคริปต์ที่เจ้าของช่องใช้เองเพื่อดึงสถิติวิดีโอของช่องตัวเอง (ยอดวิว ระยะเวลาการดู ไลก์ คอมเมนต์) ผ่าน YouTube API แบบอ่านอย่างเดียว ข้อมูลเก็บไว้บนคอมพิวเตอร์ของเจ้าของช่องเท่านั้น ไม่ส่งต่อหรือขายให้ใคร และไม่เข้าถึงข้อมูลของผู้ใช้อื่น

The "howitworksth stats" app is a private script used only by the channel owner to read their own channel's statistics through the YouTube Data and Analytics APIs (read-only). Data stays on the owner's computer and is never shared or sold. Use of Google API data follows the Google API Services User Data Policy. You can revoke access anytime at myaccount.google.com/permissions.
